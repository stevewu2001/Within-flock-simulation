### Mixed-Species SEIRD Model for H5N1 ###

# This project contains code that generates time series of a stochastic model. 
# It is accompanied by Jupyter notebook files that generate plots to help visualise the results.

### How to use ###
1. Use run_main_results.py to generate the time series, 
1.5. Optionally also run run_sensitivity.py and run_totpop_vary.py for sensitivty analysis.
2. Run_detection_time_compare.ipynb for most of the plots found in the paper, some variables inputs must be manually changed.
3. Use the other ipynb files to see the result of sensitivity analysis or additional time series plots.

### Project Structure ###
- `run_main_results.py` → Generates core simulation outputs  
- `run_sensitivity.py`, `run_totpop_vary.py` → Sensitivity analyses  
- `*.ipynb` → Visualization and analysis notebooks
